# Loading all anise datasets

Loading all anise datasets

## Usage

``` r
data_anise(envir = .GlobalEnv)
```

## Arguments

- envir:

  The environment where the datasets will be loaded. Defaults to the
  global environment.

## Value

Load the `taxonomy`, `taxonomy_identifiers`,`introudction`, `origin` and
`meow` datasets.
