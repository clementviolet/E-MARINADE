## Versioning rule

ANIS-E follows semantic dataset versioning:

- **MAJOR**: incompatible schema or identifier changes
- **MINOR**: new records, new sources, or new data added without breaking the schema
- **PATCH**: corrections to existing data, metadata, or documentation without changing the schema

## Current release summary

This release provides a corrected version of the dataset. It fixes a data-processing issue that caused some records to be overwritten and others to be duplicated, affecting a subset of taxa. No schema changes were introduced.

No schema change was made.

Primary keys and foreign-key relationships are unchanged.
